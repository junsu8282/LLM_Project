질문: 스택이 뭐야?

답변:
정의:
스택은 가장 나중에 들어온 데이터가 가장 먼저 나가는 LIFO 구조의 자료구조입니다.

동작 방식:
데이터를 넣는 연산은 Push, 꺼내는 연산은 Pop입니다. 삽입은 왼쪽에서부터 아래쪽으로, 삭제는 위쪽에서부터 아래쪽으로 이루어집니다.

장점:
구조가 단순하고 삽입과 삭제가 빠릅니다.

단점:
중간 데이터에 직접 접근하기 어렵고, 데이터가 분포되어 있으면 스택 오버플로우가 발생할 수 있습니다.

사용 예시:
함수 호출 관리, 되돌리기 기능, 괄호 검사, 웹 브라우저 뒤로 가기 버튼 동작, 게임 배치 관리 등에 사용됩니다.

질문: 스택과 큐의 차이는?

답변:
스택은 나중에 들어온 데이터가 먼저 나가는 LIFO 구조이고, 큐는 먼저 들어온 데이터가 먼저 나가는 FIFO 구조입니다. 스택은 되돌리기나 함수 호출 관리에 사용되고, 큐는 작업 대기열이나 BFS 탐색에 사용됩니다.

질문: 일반 큐와 데드락 큐 차이 알려줘

답변:
일반 큐는 작업을 넣고 꺼내는 방식이고, 데드락 큐는 작업이 끝나면 바로 종료되는 방식입니다. 일반 큐는 작업 처리 순서대로 처리하고, 데드락 큐는 가장 빠른 완료 순서대로 처리합니다.
